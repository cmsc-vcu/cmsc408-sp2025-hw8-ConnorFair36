## Getting Started

### Prerequisites

Make sure you have the following tools installed on your device:
- python
- pyenv
- poetry with the shell extention installed
- quarto

### Installation

Once you have the tools installed on your local device, you can follow these instructions to render and view the project

1. Store a copy of this repo to your device
2. Open a new terminal in the folder where your copy is stored
3. create a .env file with the database credentials needed to sign in 
4. change your global python version to version 3.12.8 with pyenv
5. run `poetry install` to get your poetry enviroment set up
6. run `poetry shell` to enter the enviroment
7. navigate into the reports folder and run `quarto render report.qmd` to update the html file
8. open the report.html file that was generated into your browser
